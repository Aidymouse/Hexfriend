# Translator Notes

## Creating a Translation

If you'd like to translate Hexfriend, simply fork the repo, create a translation file for your language that implements the right type, and add your translation to the translation_map in `translation.ts`. Submit a pull request and it's most likely your translation will make it in!

Let Aidan (aidan.habedank@gmail.com) know if you'd like a credit on the website.
